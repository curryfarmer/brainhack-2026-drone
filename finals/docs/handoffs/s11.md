## Workstream A — the no-tracking pipeline (build first; no briefing needed)
Reuses the SIM-5 flight whole: `finals/configs/sitl3_vision.json`, 3 PX4,
llvmpipe, cam `update_rate 5`, RTF 0.86, `sim/run_vision.sh stageB3`.

1. **3 cars, 3 directions.** `sim/convoy_driver.py` already publishes
   **per-robot** `/model/convoy_robot_<id>/cmd_vel` (~line 79) but sends the same
   Twist to all → circle. Twist is **body-frame** (`linear.x` = forward along the
   robot's spawn heading; `angular.z` = yaw-rate). Give each robot its own
   `(linear, angular=0)` + **3 distinct spawn yaws** → 3 diverging straight lanes.
   Re-pose 3 of the 5 robots into a cluster with 3 yaws in
   `sim/worlds/convoy_px4.sdf` (current = circle, centre (0,−2), R=2: robot_7
   (0,0), _11 (−1.9,−1.4), _23 (−1.2,−3.6), _42 (1.2,−3.6), _88 (1.9,−1.4)), or
   fork a small `convoy_3lane.sdf`. Keep `vel_at()` a pure function of elapsed
   time (two-run determinism — SIM-3 invariant).

2. **One drone per lane.** Set each instance's `PX4_GZ_MODEL_POSE` in
   `run_vision.sh launch3` (today alpha (1.2,0.2)/bravo (−1.2,0.2)/charlie (0,−2))
   to sit over a point on its car's path. Nadir footprint radius ≈
   band·tan(49.8°) ≈ **1.18·band** (band 1.2 → ~1.4 m). Space lanes > ~3 m apart
   so footprints don't overlap → each drone sees ONLY its car's id (clean 1
   drone→1 car→1 id). Pick 3 ids (e.g. 7/23/88). Drones **hover/scan, don't
   chase** — point each where its car crosses early, or keep car speed/distance
   small enough to dwell under the footprint.

3. **Each drone reads its car's UNIQUE id.** Already works (SIM-5 per-drone
   per-id `sightings.csv`). No code.

4. **"Took a picture"** — the only real new code. Frame-save infra exists but
   only on the YOLO path: `finals/vision/detector.py::_save_annotated` (line 284)
   → `context["saved_path"]` → `Sighting.frame_path` (`types.py:108`), gated by a
   `save_dir`. The ArUco path (`finals/vision/aruco.py::_detect_aruco_with` line
   84, driven by `perception.py::PerceptionLoop.sample_once` line 446) builds
   **minimal** Sightings with `frame_path=None`.
   **Change:** on a marker sighting, draw `cv2.aruco.drawDetectedMarkers` +
   `cv2.imwrite` to a per-drone `frames/` dir and set `frame_path` (Sighting is

   `save_dir`). `replay_plot.py` + the `frame_path` CSV column already consume it.
